서술형 답안을 자동 채점하고 모범답안·해설을 바로 보여주는 연습 도구예요. 연도·회차별 실제 기출문제도 그대로 풀어볼 수 있어요.

회차 선택 문제는 실제 기출문제를 원문에 가깝게 옮겼고, 그 외 문제는 법령·KOSHA 기준으로 재구성한 연습문제예요(작업형 삽화는 AI로 만든 예시 이미지). 채점은 핵심 키워드 자동 채점이며, 애매하면 대화창에 답안을 붙여넣어 피드백받아보세요.

필답형 279문항(안전관리론 / 인간공학·시스템안전 / 기계안전 / 전기안전 / 화공안전 / 건설안전) + 작업형 128문항(기계안전 / 추락재해 / 전기안전 / 붕괴·굴착 / 질식재해 / 화재·화학 / 낙하·충돌 / 전도재해) · 진행 기록은 이 브라우저에만 저장됩니다(다른 기기·브라우저와 공유되지 않음).
실기 시험은 필답형(55점·90분)과 작업형(45점·60분)의 합산 60점 이상이 합격 기준이며, 이 도구는 두 유형 모두 서술형 답안 훈련에 초점을 맞추고 있습니다.
